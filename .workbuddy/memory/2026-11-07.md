## 追加：登录 / 退出按钮与登出链路（已实现并上线）

用户要求：「切换登录/退出按钮，退出后最终跳转到登录页面」。

**实测结论（2026-11-07，线上 curl）**：
- Cloudflare Access 官方登出端点 `https://auth.hesen.dpdns.org/cdn-cgi/access/logout` 与
  `https://seazen.cloudflareaccess.com/cdn-cgi/access/logout` 只撤销会话 + 清 Cookie，**不负责跳转**；
  无 Cookie 时 GET 返回 200 `Error ・ Cloudflare Access / No Access cookie found. Please login first.`，
  HEAD 返回 404（端点只处理 GET）。
- 登录页 URL = `seazen.cloudflareaccess.com/cdn-cgi/access/login/auth.hesen.dpdns.org?kid=<AUD>&meta=<动态签名>&redirect_url=%2F`，
  `meta` 由边缘实时生成（含 iat/exp/app_session_hash），**无法硬编码**；不带 meta 直连会 302 回 `/` 再由边缘补发。
- 未登录 `GET https://auth.hesen.dpdns.org/` → 302 到带 meta 的登录页（跟随 1 次跳转，登录页 200）。
  **因此「跳回 / 让 Access 302」是唯一可靠的登录页落点。**
- 官方登出是全局撤销，旧 token 约 20–30 秒失效；IdP 若仍登录可能 SSO 自动重登。

**实现**：
- `src/render.js`：`shell()` 顶栏在所有页面加邮箱 + 「退出登录」(`/logout`)；新增 `renderLogoutPage(snapshot)`
  退出中间页（独立 HTML + 内联脚本）：同源 fetch + 隐藏 iframe 触发应用域名与 team 域名的官方登出端点 →
  延时 `location.replace('/')` → Access 302 到登录页；提供「立即重新登录」与用 TEAM_DOMAIN+kid 构造的
  「直接打开 Access 登录页」兜底。`renderForbidden` 加第三参数 `showLogin`，403 页提供「前往 Access 登录页」。
  `hero()` 里原来那个指向 team 域名 logout 的「切换登录方式/退出」链接已移除（它会落在 App Launcher 而非登录页）。
- `src/index.js`：新增 `GET /logout`（不写入 D1 登录日志）、404 提示补 `/logout` 且 404 页不显示登录按钮。
- dev 模式：退出页 `devMode=true` 时不触发登出请求、不自动跳转，只显示降级说明 + 「返回首页（重新登录）」。
- `scripts/render-preview.mjs`：新增 `public/logout-preview.html`（生产态，直接调 renderLogoutPage），
  冒烟断言扩到 20 项，新增 403 页登录入口检查。
- `README.md` 新增「登录 / 退出」章节，`docs/SETUP.md` 新增 §14（含实测依据表），顺手修正 §13
  「wrangler dev 会注入 .dev.vars 全部键」的过时描述（已由 `secrets.required: []` 隔离）。

**验证**：`npm run check`、20 项预览冒烟全绿；wrangler dev 端到端 `/`、`/logs`、`/logout` 均 200、
顶栏按钮存在、dev 降级正确、POST /logout 405、未知路径 404、`/logout` 不增加日志 total(1→1)、
